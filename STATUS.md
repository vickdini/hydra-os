Works so far:
- Decision: our own installer window in Python + PyQt6 (like Hydra Apps), NOT Calamares. Why: Calamares is in Ubuntu 26.04 (3.3.14) but its disk page needs KPMcore + libparted + udev, which see only "known" Linux filesystems and real block devices; Hydra's pool partition is neither, and the installer must never mount the target. Its install modules (unpackfs, bootloader, users) all work by mounting the new system and changing files inside it, which our design forbids (settings are applied at first boot instead). It would also pull in about 30 extra libraries (Qt Quick/QML, KF6 parts, yaml-cpp, os-prober).
- The installer window: all 8 pages render and behave (Next only enabled when the page is complete, password mismatch shown in red, disk too small / installation stick shown greyed out with the reason, red "everything will be deleted" box with a tick box). Checked as pictures on Windows with sample data (scratch/g-shots-win), not yet inside Hydra.
