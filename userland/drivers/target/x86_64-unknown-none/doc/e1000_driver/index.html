§Hydra e1000 network driver

Drives an Intel 82540EM (e1000) network adapter from Ring 3, in an address space of its own: its registers are the device memory the supervisor granted (PCI BAR0), its descriptor rings and packet buffers DMA memory it allocates. The kernel enumerates PCI (enabling bus mastering) and starts it with bar0=<phys> irq=<line>.

The driver only answers requests. When the adapter interrupts, the kernel masks the line and wakes its network task, which asks for the received frames; the driver acknowledges the interrupt causes and unmasks the line then.

Requests on ENDPOINT_NET_DEV (frames travel through the service window):

  • MSG_NET_TRANSMIT [len]: send the frame at the start of the window;
  • MSG_NET_RECEIVE: fill the window with received frames, each a 16-bit little-endian length then its bytes; reply [0, frame count];
  • MSG_NET_GET_MAC: reply [0, MAC bytes 0..4, MAC bytes 4..6];
  • MSG_NET_GET_STATUS: reply [0, link up].
