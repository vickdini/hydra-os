§Video Subsystem: Microkernel Wayland Surface & Window Compositor

Provides the core Wayland surface abstraction, window hierarchy, and input routing.

§Architectural Role & Design Rationale

In standard Wayland architectures, clients allocate pixel buffers and attach them to wl_surface objects. The compositor handles window decorations (or accepts client-side decorations), manages the window stacking order (z-index), processes input focus (wl_seat), and composites surfaces into the display raster.

This module implements the internal microkernel representation of Wayland surfaces, top-level application windows (xdg_toplevel), and desktop window interaction (movement, focusing, minimize, maximize, and close).

§Key Types & Interfaces

  • WlSurface: Represents an individual window surface with title, bounds, and content state.
  • WindowType: Supported desktop application types (Konsole Terminal, KSysGuard Monitor, About).
  • WaylandCompositor: Central registry managing surface lifecycle, z-ordering, and drag state.
