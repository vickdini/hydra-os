KDE Plasma-style desktop shell rendering (panel, launcher, widgets).

§Video Subsystem: KDE Plasma 6.8 “Breeze” Desktop Shell

Renders an authentic KDE Plasma 6.8 Wayland desktop environment complete with dark Breeze theme, floating translucent panel, Kickoff application menu, official Breeze SVG icons, and interactive window manager.

§Architectural Role & Design Rationale

Hydra OS implements a desktop user interface modeling the KDE Plasma 6.8 workspace:

  • Genuine KDE Plasma 6.8 Assets: Downscaled upstream 5120x2880 dark ScarletTree wallpaper, official Breeze icons (Konsole, KSysGuard, Dolphin, System Settings, KDE Plasma Kickoff).
  • Breeze 6 Theme Engine: Cohesive color palette utilizing Plasma blues (#3daee9, #1d99f3), slate darks (#1b1e20, #232629, #31363b), and danger accents (#da4453).
  • Floating Bottom Panel: Plasma 6 signature floating dock detached 8px from bottom with rounded corners, Kickoff launcher, active task tabs with focus indicators, and live system tray.
  • Window Management: Breeze window decorations, circular control buttons, titlebars, and tear-free Wayland surface blitting.
