§Hydra display server

Owns the framebuffer and draws the built-in Plasma-style desktop, in Ring 3 in an address space of its own. The supervisor starts it with the framebuffer’s geometry, fb=<phys>:<width>:<height>:<stride>:<bgr>, and whether a disk is attached, disk=ata (for the system monitor widget); it may map only that framebuffer.

Requests on ENDPOINT_DISPLAY_DEV:

  • MSG_FB_GET_INFO: framebuffer address, width | height << 32, stride | bgr << 32, size;
  • MSG_FB_INPUT_EVENT: pointer motion (1), button (2) or typed character (3);
  • MSG_FB_FLUSH: draw a frame and show it.
