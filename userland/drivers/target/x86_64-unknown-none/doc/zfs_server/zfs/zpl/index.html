§ZFS POSIX Layer (ZPL)

§Subsystem Role & Architecture

This module implements the POSIX filesystem abstraction layer on top of Hydra’s OpenZFS storage stack. It provides standard file and directory semantics (creation, deletion, links, truncation, read, write, permissions, and directory iteration) operating directly on dnode objects. Errors are returned as negative Linux errno values.

§Key Types & Interfaces

  • Attr: Inode attribute descriptor matching Linux struct stat semantics.
  • SetAttr: Modification mask for changing permissions, sizes, and timestamps.
  • ReaddirEntry: Iteration element returned during directory listings.
  • ZplResult: Canonical Result type encoding negative POSIX error codes.

§Concurrency & Safety

The ZPL operates under the super::server::ZFS_SERVER spinlock or VFS synchronization primitives. Modifications increment transaction groups and synchronize blocks via the DMU.
