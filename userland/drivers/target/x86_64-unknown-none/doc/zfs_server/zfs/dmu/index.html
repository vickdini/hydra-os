§Data Management Unit (DMU)

Turns the block-level pool into numbered objects of arbitrary size. Each object is a DnodePhys plus a tree of block pointers (3 top-level pointers, 64-way indirect blocks, nlevels deep). Object N’s dnode is stored at byte N * 512 of object 0, the meta object, whose own dnode lives in the uberblock.

§Transaction Model

Writes never touch the on-disk tree directly. Modified 4 KiB blocks are kept as dirty frames keyed by (object, block id), truncations and object frees are recorded, and reads overlay them on the committed tree. Dmu::sync then commits one transaction group: every dirty block is written to a newly allocated location, indirect blocks are rewritten bottom-up, dnodes are written into the meta object, the meta object’s tree is committed last, and the SPA writes the new uberblock. Replaced blocks are freed only after that (see super::spa), unless a snapshot still references them.
