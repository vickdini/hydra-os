pub fn probe(vdev: &Vdev) -> Option<DiskContents>

Probes block 0 of a device to determine its contents: nothing (all zeros), a pool label, or foreign data. Read errors are retried; returns None if device read fails.

Source

Opens an existing pool, returning it with its newest valid uberblock, or hands the device back if it holds no valid pool.

Marks the bits past the end of the device in the last bitmap word as used so the allocator never returns them (in memory only; not counted as allocated).
