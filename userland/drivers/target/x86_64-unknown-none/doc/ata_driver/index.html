§Hydra ATA disk driver

Drives the primary master IDE/ATA disk from Ring 3, in an address space of its own: port I/O for commands and polled PIO transfers, bus-master DMA through a bounce buffer when the controller supports it. Interrupts stay off (nIEN): completion is polled.

The supervisor starts it with the controller’s ports: io=<base> ctrl=<port> and, when the PCI IDE controller can bus-master, bm=<base> (the kernel enumerates PCI and enables bus mastering).

Requests on ENDPOINT_BLOCK_DEV (blocks are 4 KiB; data is in the service window at byte offset args[2]):

  • MSG_BLOCK_READ [block, count, offset], MSG_BLOCK_WRITE [block, count, offset];
  • MSG_BLOCK_FLUSH: flush the disk’s write cache;
  • MSG_BLOCK_GET_SIZE: reply [0, blocks, lba48, dma], the model (40 bytes) in the window.

Replies are MSG_BLOCK_REPLY [status (0 or -errno), blocks transferred].
