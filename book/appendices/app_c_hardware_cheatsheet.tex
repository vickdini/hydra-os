\chapter{x86\_64 Hardware and Architectural Reference}
\label{app:hardware}

This appendix provides a definitive hardware cheatsheet for systems engineers developing bare-metal operating system software on the x86\_64 Long Mode architecture. It summarizes CPU registers, processor flags, control registers, Model-Specific Registers (MSRs), hardware exception vectors, and standard PC I/O port assignments.

\section{Processor Status Flags: The \texttt{RFLAGS} Register}
\label{sec:rflags_ref}

\begin{table}[htbp]
\centering
\small
\begin{tabularx}{\textwidth}{rllX}
\toprule
\textbf{Bit} & \textbf{Name} & \textbf{Mnemonic} & \textbf{Architectural Function} \\
\midrule
0 & Carry Flag & \texttt{CF} & Set on unsigned arithmetic overflow or borrow. \\
2 & Parity Flag & \texttt{PF} & Set if least-significant byte of result contains an even number of 1s. \\

6 & Zero Flag & \texttt{ZF} & Set if mathematical result equals zero. \\

10 & Direction Flag & \texttt{DF} & String processing direction (\texttt{0}=increment, \texttt{1}=decrement). \\
11 & Overflow Flag & \texttt{OF} & Set on signed two's complement integer overflow. \\
12--13 & I/O Privilege & \texttt{IOPL} & Specifies privilege ring (0..3) required to execute PMIO instructions. \\
14 & Nested Task & \texttt{NT} & Controls task chaining (must be \texttt{0} in Long Mode). \\
16 & Resume Flag & \texttt{RF} & Suppresses instruction breakpoint exceptions. \\

18 & Alignment Check & \texttt{AC} & Enables memory alignment fault detection for Ring 3. \\
19 & Virtual Interrupt & \texttt{VIF} & Virtualized copy of \texttt{IF} for virtual 8086 mode. \\
20 & Virtual Pending & \texttt{VIP} & Indicates virtualized interrupt is pending. \\
21 & CPUID Identification & \texttt{ID} & If software can toggle this bit, the \texttt{cpuid} instruction is supported. \\

\section{Control Registers (\texttt{CR0}, \texttt{CR2}, \texttt{CR3}, \texttt{CR4})}
\label{sec:cr_ref}
% ==============================================================================

\subsection{\texttt{CR0}: System Control Flags}
\begin{itemize}
    \item \textbf{Bit 0 (\texttt{PE}, Protection Enable):} Activates protected mode when set.
    \item \textbf{Bit 1 (\texttt{MP}, Monitor Coprocessor):} Controls interaction of \texttt{wait}/\texttt{fwait} with the \texttt{TS} flag.
    \item \textbf{Bit 2 (\texttt{EM}, Emulation):} When set, floating-point instructions trigger a \texttt{\#NM} exception for software emulation.
    \item \textbf{Bit 3 (\texttt{TS}, Task Switched):} Set by hardware on context switch; used for lazy FPU state restoration.
    \item \textbf{Bit 16 (\texttt{WP}, Write Protect):} When set, the CPU prohibits Ring~0 supervisor code from writing into read-only user pages, preventing kernel-space Copy-on-Write subversion.
    \item \textbf{Bit 31 (\texttt{PG}, Paging):} Activates virtual memory translation. Must be set for Long Mode.
\end{itemize}

\subsection{\texttt{CR2}: Page Fault Linear Address}
When a Page Fault (\texttt{\#PF}, Exception 14) occurs, the CPU automatically deposits the faulting 64-bit virtual address into \texttt{CR2} before jumping to the interrupt handler.

\subsection{\texttt{CR3}: Page Directory Base Register (PDBR)}
Holds the 64-bit physical base address of the Level~4 Page Map (PML4) table. If Process-Context Identifiers (\texttt{PCID}) are enabled via \texttt{CR4.PCIDE}, bits 11:0 encode the 12-bit PCID tag.

\subsection{\texttt{CR4}: Architectural Feature Extensions}
\begin{itemize}
    \item \textbf{Bit 5 (\texttt{PAE}, Physical Address Extension):} Must be \texttt{1} to enable 64-bit Long Mode.
    \item \textbf{Bit 7 (\texttt{PGE}, Page Global Enable):} Retains translation entries marked with the \texttt{GLOBAL} flag in the TLB across \texttt{CR3} writes.
    \item \textbf{Bit 9 (\texttt{OSFXSR}, OS Fast FXSAVE/FXRSTOR):} Enables fast 512-byte x87/SSE FPU register save and restore instructions.
    \item \textbf{Bit 10 (\texttt{OSXMMEXCPT}):} Enables unmasked SSE SIMD floating-point exceptions (\texttt{\#XM}).
    \item \textbf{Bit 17 (\texttt{PCIDE}, PCID Enable):} Activates Process-Context Identifiers for TLB tagging.
    \item \textbf{Bit 20 (\texttt{SMEP}, Supervisor Mode Execution Prevention):} Prevents Ring~0 code from executing instructions located in user-accessible pages, neutralizing privilege-escalation exploits.
    \item \textbf{Bit 21 (\texttt{SMAP}, Supervisor Mode Access Prevention):} Prohibits Ring~0 code from reading or writing user pages unless explicitly permitted by the \texttt{stac} instruction.
\end{itemize}

\section{Model-Specific Registers (MSRs)}
\label{sec:msr_deep}
% ==============================================================================

MSRs are 64-bit hardware registers manipulated via the assembly instructions \texttt{rdmsr} (read with MSR index in \texttt{ECX}, returning result in \texttt{EDX:EAX}) and \texttt{wrmsr} (write with value in \texttt{EDX:EAX}):

\begin{table}[htbp]
\centering
\small
\begin{tabular}{lll}
\toprule
\textbf{MSR Index} & \textbf{MSR Name} & \textbf{Architectural Function} \\
\midrule
\texttt{0x0000\_001B} & \texttt{IA32\_APIC\_BASE} & Base address and enable flags for Local APIC. \\
\texttt{0xC000\_0080} & \texttt{IA32\_EFER} & Extended Feature Enable Register (\texttt{LME}, \texttt{LMA}, \texttt{NXE}). \\
\texttt{0xC000\_0081} & \texttt{IA32\_STAR} & GDT Code/Data Segments for \texttt{syscall} and \texttt{sysret}. \\
\texttt{0xC000\_0082} & \texttt{IA32\_LSTAR} & 64-bit RIP entry point for the \texttt{syscall} instruction. \\
\texttt{0xC000\_0083} & \texttt{IA32\_CSTAR} & Compatibility Mode target RIP for 32-bit \texttt{syscall}. \\
\texttt{0xC000\_0084} & \texttt{IA32\_FMASK} & Mask of \texttt{RFLAGS} bits cleared upon \texttt{syscall} execution. \\
\texttt{0xC000\_0100} & \texttt{IA32\_FS\_BASE} & 64-bit base address for Thread-Local Storage (\texttt{FS}). \\
\texttt{0xC000\_0101} & \texttt{IA32\_GS\_BASE} & 64-bit base address for per-CPU kernel data structures (\texttt{GS}). \\
\texttt{0xC000\_0102} & \texttt{IA32\_KERNEL\_GS\_BASE}& Target swapped with \texttt{GS\_BASE} by the \texttt{swapgs} instruction. \\
\bottomrule
\end{tabular}
\caption{Primary Model-Specific Registers Configured by Hydra.}
\label{tab:msr_complete}
\end{table}
